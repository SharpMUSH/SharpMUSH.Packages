# sheet-fabula-help

Puts the JRPG sheet's topics into `+help` (`+help sheet`, `+help check` and their subtopics, and the staff and settings
topics) by registering the sheet's help object with the `plus-help` librarian, and points the sheet's
"no such switch" message at `+help`. A bridge between [`sheet-fabula`](../sheet-fabula/) and `plus-help`.

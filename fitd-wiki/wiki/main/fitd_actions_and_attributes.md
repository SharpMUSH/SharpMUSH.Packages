Every sheet has twelve actions, rated 0 to 4, under three attributes: Insight, Prowess and Resolve.
Type an action's key, or the start of its name, in commands. `+sheet/traits` lists the ones your game uses,
which may differ from these.

An action rolls one die for each point of its rating. An attribute rolls one die for each of its actions rated
1 or more, when you resist.

## Insight

| Action | Key |
|---|---|
| Hunt | `hunt` |
| Study | `study` |
| Survey | `survey` |
| Tinker | `tinker` |

## Prowess

| Action | Key |
|---|---|
| Finesse | `finesse` |
| Prowl | `prowl` |
| Skirmish | `skirmish` |
| Wreck | `wreck` |

## Resolve

| Action | Key |
|---|---|
| Attune | `attune` |
| Command | `command` |
| Consort | `consort` |
| Sway | `sway` |

## Example

With Finesse 1, Prowl 0, Skirmish 2 and Wreck 0, Prowess is 2: `+check/resist prowess` rolls two dice.

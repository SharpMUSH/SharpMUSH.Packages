# Harbor Lights

A theme package: two portal themes for a seaside game.

| Theme | Mode | Look |
|---|---|---|
| Harbor Night | dark | Lamplight over a dark harbour under a lighthouse; amber accent, frosted cards with a lamp-coloured edge |
| Harbor Morning | light | The same harbour at first light; sea-blue accent, frosted cards with a sea-coloured edge |

Each carries its colours and style choices, a stylesheet (`harbor-night.css`, `harbor-morning.css`), a background
picture of the harbour and a compass mark beside page titles (`images/`). The art is original to this package.

## Installing

Admin → Packages, find **Harbor Lights**, review and apply. Both themes appear in every character's theme menu
without a reload, and in Admin → Themes with a **Package** tag. To make one the game's default, choose it there.

A new version of the package replaces both themes. Uninstalling removes them; it is refused while either is the
game's default for its mode. Characters who chose a removed theme see the game's default.

Needs SharpMUSH 1.2 or later (package format 1.21).

## Changing it

The installed themes are read-only. **Duplicate** one in Admin → Themes to make the game's own copy, colours and
stylesheet included, and change that.

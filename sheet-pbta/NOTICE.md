# Dungeon World Notice

The sheet-pbta package's example stats (Str, Dex, Con, Int, Wis, Cha) and the moves on its store whose
`SOURCE` is Dungeon World are taken from Dungeon World. Those moves are the eight basic moves (Hack and
Slash, Volley, Defy Danger, Defend, Spout Lore, Discern Realities, Parley, Aid or Interfere) and the special
moves Last Breath, Take Watch, Undertake a Perilous Journey, Carouse, Supply, Recruit and Outstanding
Warrants.

## Changes

Each move is stored as its whole text and, separately, the sentences for each result (a full hit, a partial
hit, a miss). Where a result refers to a list in the move, the list is repeated with that result, and the
sentence that follows a list (Discern Realities) is repeated with each result that uses it. Bold type is
dropped, and list items are written as lines beginning `- `. No words are changed.

That repository also includes material from the System Reference Document 5.1 (CC BY 4.0) in its monsters
and spells. This package takes none of it.

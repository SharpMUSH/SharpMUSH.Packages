# fabula-wiki

The rules of the JRPG sheet as wiki pages, for players to read in the portal's wiki and with `+wiki`:
character creation, checks, Fabula Points and bonds, resources, defences and levels, status effects,
the Core Rulebook's fifteen classes, and a page on the commands that play them on this game.

This is a **content pack**: wiki pages only, with no objects or softcode. Softcode never reads these
pages. The sheet that plays the rules is [`sheet-fabula`](../sheet-fabula/); neither package needs the
other.

Compatible with Fabula Ultima, and requires the Fabula Ultima Core Rulebook: see [NOTICE.md](NOTICE.md).
The pages state the rules in their own words and hold no skill, spell or item descriptions.

## What it installs

The wiki collection is named **JRPG**, and its landing page is **Start here — JRPG rules**, pinned to
the wiki home.

| Namespace | Pages |
|---|---|
| Category | Start here — JRPG rules |
| Main | Character Creation, Checks, Fabula Points and Bonds, Resources and Levels, Status Effects, Classes, JRPG on this game |
| Help | JRPG Rules License Notice (wiki admins only may edit or delete it) |

Every page ends with a line linking the licence notice page. Page names start with `fabula_`, so the
rules of other systems can share the wiki.

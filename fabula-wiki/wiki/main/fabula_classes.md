The fifteen classes of the Core Rulebook, and what each class's first level gives. A game can add the classes of other books.

| Class | First level gives |
|---|---|
| Arcanist | +5 MP |
| Chimerist | +5 MP, rituals |
| Darkblade | +5 HP, martial melee weapons and martial armour |
| Elementalist | +5 MP, rituals |
| Entropist | +5 MP, rituals |
| Fury | +5 HP, martial melee weapons and martial armour |
| Guardian | +5 HP, martial armour and martial shields |
| Loremaster | +5 MP |
| Orator | +5 MP |
| Rogue | +2 IP |
| Sharpshooter | +5 HP, martial ranged weapons and martial shields |
| Spiritist | +5 MP, rituals |
| Tinkerer | +2 IP |
| Wayfarer | +2 IP |
| Weaponmaster | +5 HP, martial melee weapons and martial shields |

Each class's skills are in the Core Rulebook. `+sheet/traits` lists the classes this game knows.

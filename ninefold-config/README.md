# ninefold-config

A bridge between [`ninefold`](../ninefold/) and `plus-config`: staff see and change the Ninefold settings with
`+config ninefold`. Without it, `ninefold` keeps its defaults.

| Setting | Default | What it does |
|---|---|---|
| `challenge` | 600 | Seconds a challenge waits for an answer |
| `overtime` | 3 | Rounds a drawn game is played under Overtime, the first included |
| `logkeep` | 500 | Card log lines kept |

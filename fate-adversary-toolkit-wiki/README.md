# fate-adversary-toolkit-wiki

The Fate Adversary Toolkit rules as wiki pages: enemies and filler groups, obstacles, and
constraints, with the commands of [`fate-adversary-toolkit`](../fate-adversary-toolkit/) that play
them. Brings [`sheet-fate-wiki`](../sheet-fate-wiki/), whose pages these link to.

Based on the Fate Adversary Toolkit SRD under CC BY 3.0: see [NOTICE.md](NOTICE.md). An unofficial
fan package, not affiliated with or endorsed by Evil Hat Productions.

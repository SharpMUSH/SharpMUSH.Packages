# sheet-charge-help

Puts the Charge sheet's topics into `+help` (`+help sheet`, `+help check`, `+help clock`, and the staff and settings
topics) by registering the sheet's help object with the `plus-help` librarian, and points the sheet's
"no such switch" message at `+help`. A bridge between [`sheet-charge`](../sheet-charge/) and `plus-help`.

**Tech 5 System**
3 Slots · Salvage Value 3

Developed by Stefanus initially to repair the intricately complex mechanisms within the Neura-Phage Chassis, this system can fix up some of the most advanced tech out in the wastes.

### {cost=2EP} Patch

**Turn Action // Range: Close**

You restore up to 8 Structure Points to any Mech in Range that has at least 1 SP.

### {cost=2EP} System Repair

**Short Action // Range: Close**

You repair a damaged Tech 1, 2, 3, 4, or 5 System or Module in Range to Intact Condition. It is now usable.

### {cost=4EP} Chassis Repair

**Long Action // Range: Close**

You repair a damaged Tech 1, 2, 3, 4, or 5 Mech Chassis or Vehicle in Range to Intact Condition. It is now usable with 1 SP.

**Tech 1 Module**
1 Slots · Salvage Value 3 · 2 EP · Medium Range · Turn Action
Traits: Hacking

This hacking program developed by Stefanus Industries allows you to tap into a Mech, database, or computer system to gather information about it. This can only be used to read data and not to write or manipulate it.

When activated, choose a target Mech, database, or computer system within Range.

Rolls on the [[Eggs Mayhem Table|main:su_table_eggs_mayhem]].

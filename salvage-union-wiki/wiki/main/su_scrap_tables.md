These tables are intended to provide a flavour to salvaging Scrap. Whilst the system is purposefully abstracted with, for example, all Tech 1 Scrap effectively being identical for game purposes, it can be interesting to describe Scrap in different ways to players as long as they are clear of its game value.

You may, for example, describe Pilots salvaging the circuitry from a broken down computer mainframe then tell them it counts as Tech 2 Scrap. This is not a definitive list and is intended for narrative and descriptive purposes.

See the Scrap macro, or the following tables:

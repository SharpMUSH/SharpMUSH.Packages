# salvage-union-wiki

The Salvage Union rules as wiki pages, collected as **Salvage Union** with its landing page at
`category:salvage_union_start_here`:

- a page for each page of the rules journals, in a category for its chapter: Core Rules, Pilot Bay,
  Mech Workshop, Union Crawler, Salvaging, Denizens of the Wasteland, and Keywords and Traits;
- a page for each chassis blueprint, with its stats and patterns;
- a page for each ability, mech system, module, piece of pilot equipment and table, linked from
  the rules that name them;
- "Salvage Union on this game", the commands of [`sheet-salvage-union`](../sheet-salvage-union/).

A content pack: wiki pages only. It does not need the sheet, and the sheet does not need it.

Unofficial, under the Salvage Union Open Game Licence 1.0b: see [NOTICE.md](NOTICE.md). Every
page is generated by [`tools/salvage-union/wiki.mjs`](../tools/salvage-union/); change the
generator and run it again rather than editing a page.

# sheet-brp-help

Puts the percentile (BRP) sheet's topics into `+help` (`+help sheet`, `+help check`, and the staff and settings
topics) by registering the sheet's help object with the `plus-help` librarian, and points the sheet's
"no such switch" message at `+help`. A bridge between [`sheet-brp`](../sheet-brp/) and `plus-help`.

**Class Feature 9**  
**Traits:** [[Alchemist|main:alchemist]]  
**Class:** [[Alchemist|main:alchemist]]

---

You know your formulas so well that you can concoct two items at once.

When using the [[Quick Alchemy|main:quick_alchemy]] action, you can create two items. These items don't have to be the same. If you create two consumables, you have to expend a versatile vial for each one.

*Source: Player Core 2.*

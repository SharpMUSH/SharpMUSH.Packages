**Class Feature 17**  
**Traits:** [[Alchemist|main:alchemist]]  
**Class:** [[Alchemist|main:alchemist]]

---

You're permanently [[Quickened|main:quickened]], and can use the extra action only to use [[Quick Alchemy|main:quick_alchemy]] to create a quick vial. You can create only one vial with this action, even if you have [[Double Brew|main:double_brew]] or a similar ability.

*Source: Player Core 2.*

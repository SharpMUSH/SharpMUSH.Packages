**Class Feat 1** (1 action)  
**Traits:** [[Alchemist|main:alchemist]]

---

You keep your bombs and bomb-related reagents in easy-toreach pouches from which you draw without thinking. You Interact to draw a bomb, draw a versatile vial, or use [[Quick Alchemy|main:quick_alchemy]] to create a bomb, then [[Strike|main:strike]] with the bomb. If you have the ability to create more than one bomb at a time with Quick Alchemy (such as from the double brew class feature), you can Strike with only one of the bombs you create with this action.

*Source: Player Core 2.*

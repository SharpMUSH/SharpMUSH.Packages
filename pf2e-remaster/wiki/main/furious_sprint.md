**Class Feat 10** (2 actions)  
**Traits:** [[Barbarian|main:barbarian]], Rage

---

You rush forward. Stride up to five times, or up to eight times if you used 3 actions. All this movement must be in a straight line (though the GM might allow reasonable variance). You can replace any of these Strides with a [[Balance|main:balance]] action if you need to, which you attempt using an Athletics check instead of an Acrobatics check, using the same DC.

*Source: Player Core 2.*

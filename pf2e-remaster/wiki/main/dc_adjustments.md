Raise or lower a DC when a task is easier or harder than its baseline for everyone who attempts it, or when its subject is not common.

| Difficulty | Adjustment | Rarity |
|---|---|---|
| Incredibly easy | -10 | |
| Very easy | -5 | |
| Easy | -2 | |
| Hard | +2 | Uncommon |
| Very hard | +5 | Rare |
| Incredibly hard | +10 | Unique |

The names are relative to the task: a very hard 2nd-level task is not very hard for a 10th-level character. A skill that only loosely fits can be very hard where a closely fitting one is easy; a 4th-level arcane tome is DC 19 with Arcana, perhaps 24 with Occultism.

When only one character in a group needs to succeed but everyone may try, make the check very hard or incredibly hard if it should stay uncertain.

*Source: GM Core, pp. 52-53 (Table 10-6).*

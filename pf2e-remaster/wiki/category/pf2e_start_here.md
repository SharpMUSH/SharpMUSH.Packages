New to Pathfinder Second Edition? Begin with [[Learn PF2e|main:learn_pf2e]], then follow the [[Character Creation Guide|main:character_creation_guide]]. This collection uses the **Remaster** rules; the learning path explains the source scope and how to use this reference.

Choose a complete starting character after the creation checklist:

- [[Dwarf Fighter Example|main:dwarf_fighter_example]] → [[First Encounter|main:first_encounter]] for movement, attacks, defenses and a separate Trip practice lesson.
- [[Dwarf Wizard Example|main:dwarf_wizard_example]] → [[Wizard Learning Guide|main:wizard_learning_guide]] for a spellbook, daily preparations, casting and resource tracking.

Then read [[Dying and Recovery|main:dying_and_recovery]] and use [[Leveling Up|main:leveling_up]] for the first advancement examples. Each practice lesson states its starting conditions; do not carry a reset exercise's resources into a different lesson.

For a rules lookup during play, browse [[Actions|category:actions]], [[Conditions|category:conditions]], [[Spells|category:spells]] or [[Equipment|category:equipment]].

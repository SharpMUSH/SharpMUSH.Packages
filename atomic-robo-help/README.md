# atomic-robo-help

Puts the Atomic Robo topics into `+help` (`+help mode`, `+help mode mega`, `+help machine`,
`+help invent`, `+help brainstorm`, and the staff, settings and credits topics) by registering the
package's help object with the `plus-help` librarian, and points its "no such switch" message at
`+help`. A bridge between [`atomic-robo`](../atomic-robo/) and `plus-help`.

# atomic-robo-wiki

A rules reference for the [`atomic-robo`](../atomic-robo/) pack, installed as wiki pages: modes, making
a character with `+chargen`, mega-stunts, invention, brainstorms, and scale and machines. Players read
them in the portal's wiki and with `+wiki`.

The collection is named **Atomic Robo (unofficial)** and opens on **Start here — Atomic Robo**, pinned to
the wiki home. The **Atomic Robo License Notice** page carries the attribution; only wiki admins edit or
delete it. It depends on [`sheet-fate-wiki`](../sheet-fate-wiki/), whose Fate rules pages it links to.

Based on the Atomic Robo RPG SRD and the Fate System Toolkit under CC BY 3.0: see [NOTICE.md](NOTICE.md).
An unofficial fan package, not affiliated with or endorsed by Evil Hat Productions or the creators of
Atomic Robo. A content pack: nothing in the game reads these pages.

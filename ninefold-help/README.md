# ninefold-help

A bridge between [`ninefold`](../ninefold/) and `plus-help`: it registers the Ninefold topics with the help
librarian, so `+help ninefold` reads them, and points an unknown `+nf` switch at them.

| Topic | What it covers |
|---|---|
| `+help ninefold` | How to play, and the player commands |
| `+help ninefold board` | How the board is drawn |
| `+help ninefold cards` | Your cards and your hand of five |
| `+help ninefold rules` | The rules and stakes |
| `+help ninefold rules where` | Which rule set a game uses |
| `+help ninefold keeper` | The card keeper's commands |
| `+help ninefold rulesets` | Making rule sets and choosing where they apply |
